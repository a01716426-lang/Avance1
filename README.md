Avance 1 - Buscador de Archivos

BUSCADOR DE ARCHIVOS

En la actualidad, es común que todo usuario de un equipo inteligente almacene gran cantidad de archivos, dristribuidos en carpetas, documentos, aplicaiones, entre otros. con el paso del tiempo la tarea simple de buscar un archivo se vuelve algo tedioso al ser lento y poco eficiente.

Ante esta problematica, presento el programa de un buscador de archivos, un programa que permita al usuario localizar rapidamente un archivo, que permita al usuario ingrear el nombre y ruta del archivo para que este localize en toda las carpetas y subcarpetas mostrando como resultado la ubicacion del o los archivos que coincidad con lo buscado.

Este proyecto tiene como proposito aplicar los conocimientos adquiridos en algoritmos y fuandamentos de programacion.

Para esta primer entrega, se entrega el pseudocodigo del programa capaz de encontrar archivos por coincidencias en su nombre, con posibilidad de mejora y expansion a futuras entregas.
