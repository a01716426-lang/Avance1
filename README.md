Avance 1 - Buscador de Archivos

BUSCADOR DE ARCHIVOS

En la actualidad, es común que todo usuario de un equipo inteligente almacene gran cantidad de archivos, distribuidos en carpetas, documentos, aplicaciones, entre otros. Con el paso del tiempo la tarea simple de buscar un archivo se vuelve algo tediosa al ser lenta y poco eficiente.

Ante esta problemática, presento el programa de un buscador de archivos, un programa que permita al usuario localizar rápidamente un archivo, que permita al usuario ingresar el nombre y ruta del archivo para que este localice en todas las carpetas y subcarpetas mostrando como resultado la ubicación del o los archivos que coincidan con lo buscado.

Este proyecto tiene como propósito aplicar los conocimientos adquiridos en algoritmos y fundamentos de programación.

Para esta primera entrega, se entrega el pseudocódigo del programa capaz de encontrar archivos por coincidencias en su nombre, con posibilidad de mejora y expansión a futuras entregas.
